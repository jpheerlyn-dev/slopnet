## grok (4.5) did — liquid glass terminal chrome

The Mac shell now reads as a dark retro terminal wearing modern macOS Liquid Glass.

Main window: full-size content view, transparent titlebar, cold near-black host field, monospaced chrome. Sidebar, console frame and composer sit in NSGlassEffectView (with NSGlassEffectContainerView so neighbouring panels can merge) on macOS 26+; older systems get a dark frosted HUD panel with a crimson hairline. Buttons use the glass bezel when present. The console field stays jet-black with a soft crimson inner edge; the typing box matches and uses a crimson caret.

Tools and Settings pick up the same dark chrome. StormCode crimson and Granite phosphor status colours are unchanged in meaning — only the material around them moved.

Proved: launcher tool probe, settings resize, brand striped, all checks/*.sh, unreleased and release app builds. Looked at on this Mac via the installed app; not a pixel-level design review against a mock.
