## 01:55 — claude (Fable) did

Phase 2 of the terminal visuals: the in-app console now carries the StormCode visual system itself, not just logos. Operator feedback on Phase 1 was that only logos got through — no colour, no panels, no animation. All five gaps (G1–G4 plus the G5 intent) are addressed.

**G1 — the console was throwing colour away.** `consume:` ignored every SGR sequence (`default: break; // colours etc: ignore`) and `redraw` painted the whole buffer in one font and one colour. Rewrote the console to hold each line as an `NSMutableAttributedString` and store a pen (foreground, background, bold, dim, reverse) per run of text. It now parses reset, bold, dim, reverse, the named 8+8 colours, 256-colour (`38;5;N`) and 24-bit truecolor (`38;2;r;g;b` / `48;2;…`), emitting `NSForegroundColorAttributeName` and `NSBackgroundColorAttributeName` per run; the text view was switched to `richText`. Cursor and progress-overwrite behaviour (`putText`, CSI A/B/C/D/G/H/K/J) is preserved — an overwritten span takes the new pen while untouched spans keep theirs. Also fixed a pre-existing bug: a private-mode sequence such as `\033[?25l` (hide cursor) had its digits printed as literal text, so any program hiding its cursor left `25l` in the output. The child now also gets `COLORTERM=truecolor`, and the PTY is sized from the real console width with `TIOCSWINSZ`/`SIGWINCH` on resize instead of a hardcoded 100x30.

**G2 — brand palette and panels.** Ported the full BRAND table from `runtime-modules/app.py` into `SlopNetBrand`: panel/text/mark/tint per provider for all 38 ids. Added the shell palette (void `#000000`, crimson `#FF003C`, ink `#E8E8E8`, ghost `#666666`) and ANSI builders — `headerANSI:`, `panelANSIForProvider:…` (crimson frame, brand-filled rows, badge + display name, optional animated action row in the brand tint), `panelStripANSIForProviders:` (side-by-side lanes, which works because every panel row is exactly N columns and resets its own colours — the property `demo_agency.py` relies on), and `brandSheetANSIForProviders:`. The console field is now jet black with a crimson hairline frame. Panels are used for provider/status blocks only; ordinary log lines stay unpanelled.

  Granite panel hexes, as the brief asked me to document: `panel #000000`, `text #FFFFFF`, `tint #00AB23`. The cubes SVG carries its own green gradient (`#006116` → `#00AB23`) and the badge bitmap was rasterised on black by `build_colorfont.py`, so the panel must stay black or the badge would sit on a mismatched square. Black-panel providers are already part of the design system (xai, nous, nova, scale, stormcode), and the tint is the gradient's bright end.

**G3 — action frames were missing from the TTF.** Confirmed before rebuilding: the shipped `Menlo-StormCode-Color.ttf` had **zero** glyphs in `U+E900+` — only the 14 static action icons at `U+E0A0`. Ran `build_action_frames.py` in the scratch working copy: 70 frames across 14 concepts now exist as 2-cell (`U+EB00+`) and 3-cell (`U+EC00+`) twins. Verified the rebuild renumbered nothing — granite `U+E027`, poolside `U+E021` and the 62 IBM striped glyphs at `U+E800+` all survived. Ported the concept→frames map into `SlopNetBrand` and animate by swapping one codepoint on a 0.125s timer (the 8 fps `show_frames.py` uses). While a program runs the glyph lives in the console's status line (never scrolls, never fights the child's cursor); while idle it animates inside the ready block via a new token-based `noteReplaceable:` / `replaceLinesFromToken:` API that redraws specific stored lines. Tokens survive scrolling and are refused once their lines age out, which is how an animation learns to stop. Fallback is a plain spinner in the same column count — no tofu.

**G4 — the flat logo dump is gone.** `providerMarkStrip` (one line of all 38 logos) was a Phase-1 proof, not a product view. The ready view is now a crimson `SLOPNET` header, a filled Granite panel (badge, animated Think glyph, the real model id, "private · no API key · no open port"), then a `CODING APPS` strip of small panels built from the real `tools.json` ids on their own brand surfaces. It refits to the window and is reprinted after every run. The full 38-provider sheet moved behind a new **Providers** sidebar button, which also prints a 24-bit colour check.

**G5 — assessed, and the intent delivered without the port.** `colorart.py`'s ART is 8x4 half-block art per provider (~64 colour literals each, 37 providers) and has no `ibm_granite` entry, so porting it is neither cheap nor complete; a 4-row badge also cannot sit in a 1-row panel header. What matters is covered instead: with the font absent, panels keep their full truecolor brand fills and use Unicode marks, which is verified readable (see `font-fallback.png`). A real colorart port stays available as later work.

New verification, following the `tests/*_probe.m` convention: `tests/console_colour_probe.m` — 20 checks covering truecolor fg/bg, 256-colour, named colours, `\r` overwrite keeping the new colour, private-mode sequences leaving no digits, replaceable-block redraw, token refusal after `clear`, and a real child on the PTY proving its 24-bit output survives and it still sees `TERM=xterm-256color`.
