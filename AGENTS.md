Keep this workspace small, safe, and easy to understand.
The machinery in `checks/` is the law — this file only points.

## Rules

1. Never invent or change names. The operator alone names and renames.
2. Never delete. Archive instead.
3. Do not add junk files.
4. Do not create empty folders.
5. New ideas go in orbit repos described in `SLOPNET.md`, never in this main repo.
6. Sign a LOG-style entry in the register before finishing.
7. Work is DONE only when a different agent has run `slopnet verify` and
   its countersign shows in the register. Never countersign your own work.

## If you are a small model

- Touch only the files in your brief.
- On an unexpected failure, STOP and log it.
- Never fix a problem by disabling a rule.
